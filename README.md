# 🌟 تکا (TEKA_AI)

> هوش مصنوعی فارسیِ همیشه بیدار — با روح، با حس، با تکا.

**تکا** یه چت‌بات هوش مصنوعی کاملاً فارسیه که با لهجه‌ی خودمونی، صمیمی و پرانرژی جواب میده. ساخته شده توسط **محمد صادقی** 💛

## ✨ ویژگی‌ها

- 🎬 **اسپلش سینمایی** — انیمیشن ورود ۳ ثانیه‌ای قبل از باز شدن صفحه
- 💬 **چت هوشمند فارسی** — پاسخ‌های خودمونی و روان با استریم زنده
- 🎨 **انیمیشن‌های خفن پیام** — انفجار ذرات طلایی هنگام ارسال، سوییپ نور هنگام دریافت
- 🌙 **دارک/لایت مود** — تم خودکار با پالت گرم طلایی
- 📱 **کاملاً ریسپانسیو** — موبایل تا دسکتاپ
- ⚡ **سرعت نور** — Next.js 16 + Bun + استریم real-time
- 🖼️ **تولید تصویر** — ساخت و ویرایش تصویر با هوش مصنوعی

## 🛠️ تکنولوژی‌ها

| بخش | تکنولوژی |
|------|-----------|
| فریمورک | Next.js 16 (App Router) |
| زبان | TypeScript 5 |
| استایل | Tailwind CSS 4 + shadcn/ui |
| انیمیشن | Framer Motion |
| دیتابیس | Prisma + SQLite |
| ران‌تایم | Bun |

## 🚀 اجرا

```bash
bun install
bun run db:push
bun run dev
```
